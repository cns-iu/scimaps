    **Link to submitted work: <https://eat-poop-you-robot.backface.net>**


    This is an AI art generation experiment that creates an endless chain of images. Each image is generated based on an AI's description of the previous image, creating an evolving visual journey that slowly drifts from one concept to another inspired by the party game "Telephone Pictionary" (also know as "Eat Poop You Cat"), where players alternately draw and describe each other's drawings.


    The system uses Flux.1-Schnell for image generation and Qwen2-VL 2B for image captioning. Each generated image becomes the prompt for the next one, creating an infinite loop of AI-generated content. Note that the chain only continues generating when someone (human or non-human - We don't verify) is watching.


    This app was programmed by an AI assistant in collaboration with a human artist developer.
